# Pocket Tools — UI 全面美化设计方案

## 概述

对 Pocket Tools（开发工具集合应用）进行全面的 UI 美化和布局升级，采用**色彩鲜艳活力风**，提升视觉品质和用户体验。

## 设计原则

- **色彩驱动**：每个工具保留专属 accent 色系，色彩作为视觉识别核心
- **干净通透**：白色/浅色卡片主体 + 色彩点缀，不牺牲可读性
- **一致体验**：所有工具页面遵循统一布局模板
- **微交互**：hover 动效、入场动画、主题切换过渡
- **深色模式**：完整支持 dark mode，自适应

## 视觉规范

### 色彩系统

保留现有 `TOOL_ACCENTS` 配置中各工具的 HSL 色值：

| 工具 | 色相 | 风格 |
|------|------|------|
| 颜色工具 | 199 (蓝) | sky |
| 文本工具 | 239 (靛蓝) | indigo |
| 时间工具 | 160 (翠绿) | emerald |
| 二维码 | 38 (琥珀) | amber |
| JSON | 271 (紫) | violet |
| 图片压缩 | 330 (粉) | pink |
| 密码生成 | 173 (青) | teal |
| 进制转换 | 24 (橙) | orange |

### 圆角

- 卡片/面板：`border-radius: 16px`
- 按钮/标签：`border-radius: 9999px`（药丸形）
- 小元素：`border-radius: 10px`

### 阴影

- 卡片常态：`box-shadow: 0 1px 4px rgba(0,0,0,0.04)`
- 卡片 hover：`box-shadow: 0 12px 28px rgba(0,0,0,0.10)`
- 面板：`box-shadow: 0 4px 20px rgba(0,0,0,0.06)`

### 字体

- 正文：系统无衬线字体（`Inter`, system-ui）
- 代码：`"JetBrains Mono", "Fira Code", ui-monospace`

## 动画与过渡

- **页面入场**：`fade-in-up`，0.4s ease-out
- **卡片入场**：stagger 延迟（每个卡片 60ms 递增）
- **卡片 hover**：上浮 4px + 阴影变化，0.25s cubic-bezier
- **主题切换**：背景/边框/文字色 0.3s ease 过渡
- **导航标签**：active 切换过渡 0.2s

## 响应式断点

| 断点 | 宽度 | 列数 |
|------|------|------|
| 手机 | < 640px | 1 列 |
| 平板 | 640-1023px | 2 列 |
| 桌面 | >= 1024px | 3 列 |

## 暗黑模式适配

- 卡片：深色背景（`bg-card`），顶部色条保留 accent 色
- 导航：深色毛玻璃
- Hero 渐变：保留色彩但降低亮度
- 文字：浅色（`text-foreground`）
- 阴影：调暗或减弱
