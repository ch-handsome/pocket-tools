# ImageTool: 图片工具（压缩 + 裁剪）

## 概述

将现有的 `ImageCompressTool` 重命名为 `ImageTool`，保留压缩功能的同时新增图片裁剪功能。使用 Tab 切换模式。

## 路由与路径

| 项目 | 旧值 | 新值 |
|------|------|------|
| 目录 | `src/pages/ImageCompressTool/` | `src/pages/ImageTool/` |
| 组件名 | `ImageCompressTool` | `ImageTool` |
| 路由路径 | `/image-compress` | `/image` |
| 配置 Key | `/image-compress` | `/image` |
| 标题 | "图片压缩" | "图片工具" |
| 配置描述 | "上传图片，调节压缩质量，实时预览" | "图片压缩与裁剪，质量调节，比例裁切" |

## 技术方案

- **裁剪库**: `react-easy-crop` — 轻量、触摸友好、支持自由/固定比例
- **Tab 切换**: 使用内置 `Card` 和 `Button` 实现，不引入额外 UI 框架
- **图片共享**: 上传的图片在两个 Tab 间共享，避免重复上传

## 组件状态

在现有状态基础上增加裁剪相关状态：

```
// 现有状态（保持不变）
originalFile, originalUrl, compressedFile, compressedUrl
quality, compressing, originalSize, compressedSize

// 新增状态
activeTab: "compress" | "crop"
crop: { x, y }              // 裁剪框位置
zoom: number                // 缩放（默认 1）
cropSize: { width, height } // 裁剪框像素尺寸
cropAspect: number | null   // 比例（null = 自由）
croppedFile: File | null    // 裁剪结果
croppedUrl: string          // 裁剪结果预览 URL
cropping: boolean           // 裁剪处理中
```

## 裁剪功能详细设计

### 图片来源
- 优先复用压缩 Tab 已上传的图片
- 裁剪 Tab 也提供独立的上传入口

### 比例切换
- "自由"（不锁定比例，aspect = undefined）
- 1:1、4:3、16:9、3:4、9:16
- 选中态高亮显示

### 确认裁剪
- 使用 Canvas 将裁剪区域绘制为新图片
- 导出为 JPEG/PNG（与原格式一致）
- 生成预览 URL，显示在结果卡片中
- 提供下载按钮

### 错误处理
- 未上传图片时禁用裁剪按钮
- 裁剪失败时显示错误提示
